### Таббар фильтрации
| Вкладка | Тултип (когда disabled) |
|---------|------------------------|
| Все | — |
| Заблокированные | "Нет заблокированных стран с указанными параметрами" |
| Разрешённые | "Нет разрешенных стран с указанными параметрами" |

### Карточка результата
```
Страна: IN (Индия)                              [Заблокирован]
Вид:                                   [Без авторизации]
Причина блокировки: Иван Иванов - JHEI2734F-39392. Длинное название...
▼ Результат в JSON
  { ... json ... }
```

**Поля карточки:**
- Страна: код + название
- Статус-тег: **Заблокирован** (красный) / **Разрешён** (зелёный)
- **Вид** (только для заблокированных):
  - templateId=1 (Геоблок) → **"Без авторизации"**
  - templateId=2 (Геоблок с авторизацией) → **"С авторизацией"**
- Причина блокировки: кликабельная ссылка (уводит на правило)
- Аккордеон: "Результат в JSON" → CodeDiff

### Empty state (до первого запроса)

## Логика взаимодействия

### Тип клиента
- **Desktop-версия** — `userAgent.clientMobile = false`
- **Мобильный** — `userAgent.clientMobile = true`
- Кнопки: одинаковая высота, поэтому лейбл должен быть коротким → "Desktop" (не "Desktop-версия")

### Тест блокировки бота
- **Пользователь** (default): `userAgent.bot = false`, `userAgent.botId = null`, дропдаун "Тип бота" скрыт
- **Бот**: `userAgent.bot = true`, автоматически выбирается Google (`botId = googleBot.id`), показывается дропдаун "Тип бота"
- При переключении обратно на Пользователь: `botId = null`, дропдаун скрывается

### Фильтр результатов
- Вкладка отключена (disabled), если в ней 0 результатов
- На disabled-вкладке показывается тултип
