# Анализ: Задача «доп параметры»

## 1. Суть задачи
Когда пользователь открывает параметры задачи (кликает на кнопку «⚙ Параметры задачи»), поле с путём к репозиторию должно автоматически заполняться глобальным путём, если для задачи он ещё не задан вручную, но глобальный путь сохранён в настройках проекта.

**Текущее поведение:** поле показывает глобальный путь только как placeholder, но остаётся пустым.

**Нужное поведение:** при раскрытии параметров, если нет собственного пути для задачи — заполнить поле значением глобального пути.

## 4. План действий

1. **Добавить watch на `showParams`** — когда параметры раскрываются (`showParams` меняется с false на true), и `taskRepoPath` пуст, а `globalRepoPath` есть, заполнить `taskRepoPath` значением `globalRepoPath`.

2. **Альтернатива: обработка при клике** — вместо watch можно добавить метод-обработчик клика на кнопку, который выполняет ту же логику: заполняет `taskRepoPath` перед раскрытием.

3. **Убедиться, что значение сохраняется** — когда `taskRepoPath` изменяется, useTaskSettings через watch уже сохраняет значение в localStorage, поэтому дополнительной логики сохранения не нужно.

4. **Протестировать поведение:**
   - Создать новую задачу, не вводить путь в параметры → при клике на параметры путь должен заполниться
   - Если в параметры уже введен путь (отличный от глобального) → не перезаписывать
   - Если глобального пути нет → параметры остаются пустыми, как раньше

5. **Проверить edge case:** если пользователь вводит путь, а потом очищает его — при следующем открытии параметров снова заполнится глобальный путь.

## 5. Ключевые файлы

- `frontend/src/components/TaskCard.vue` — компонент карточки задачи, там кнопка раскрытия параметров и поле для пути. Нужно добавить watch на `showParams` или обработчик при клике.
- `frontend/src/composables/useTaskSettings.ts` — composable для управления настройками задачи (путь, Figma URL, чекбоксы). Уже содержит логику сохранения в localStorage через watch, дополнения не требуется.
- `frontend/src/composables/useAuth.ts` — где хранятся глобальные credentials с `repoPath`. Только читаем оттуда.

## 6. Риски и нюансы

- **Перезапись значения при раскрытии:** если пользователь в тестировании или отладке ввел кастомный путь, а потом закрыл параметры и снова открыл — путь перезапишется. Это может быть неожиданно. Решение: заполнять только если поле было полностью пусто (первое открытие после загрузки страницы).

- **Синхронизация при смене глобального пути:** если пользователь откроет параметры задачи, глобальный путь заполнится. Потом он закроет параметры и изменит глобальный путь в настройках. При повторном открытии параметров той же задачи путь обновится на новый глобальный. Это логично, но стоит помнить при тестировании.

- **Сохранение в localStorage:** после заполнения `taskRepoPath`, composable useTaskSettings автоматически сохранит его в localStorage. При следующей загрузке страницы это значение уже будет восстановлено, даже если глобальный путь изменился. Это правильное поведение — задача запоминает свой путь.

Без существенных рисков, логика простая.
