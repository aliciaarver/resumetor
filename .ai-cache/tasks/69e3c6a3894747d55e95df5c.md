## 1. Что нужно сделать

Рефакторить `src/views/BuilderView.vue` (515 строк) в соответствии с архитектурой ADR-0001, разделив смешанные слои (page / widget / feature) на отдельные модули:

### Текущая проблема
`BuilderView.vue` совмещает все слои в одном компоненте:
- **Page-level:** основной layout и композиция дочерних компонентов
- **Widget-level:** табы редактирования/превью, переключатель языка, скейлинг и пагинация превью
- **Feature-level:** экспорт PDF, смена локали, сброс резюме, performance-notice
- **Entity-level:** прямые импорты сторов (resume, locale, pdfMeta)

### Что должно быть после рефакторинга

Разделить на:

1. **`src/pages/builder/`** — только страничная композиция и state переключения вкладок:
   - `BuilderPage.vue` — основной layout (две колонки / табы на мобайле)
   - Композиция: `ResomeForm` (widget) + `ResumePreviewPanel` (widget)
   - State: `activeTab` (edit/preview) для мобайла

2. **`src/widgets/resume-form/`** — левая колонка редактирования:
   - `ResumeFormWidget.vue` — контейнер с логотипом, uploader, все form-компоненты
   - Импорт из `src/components/form/*`, `src/components/upload/`
   - Логика: управление видимостью/скроллом (не UI-компоненты, они отдельные)

3. **`src/widgets/resume-preview/`** — правая колонка превью:
   - `ResumePreviewWidget.vue` — скейлинг, пагинация, sheet-layout для A4
   - Логика: useResizeObserver, measurePagedLayout, вычисления масштаба
   - Встроить логику вычисления `previewScale`, `previewNaturalHeight`, `pageOffsets`
   - Экспортирует `ref` для доступа к DOM из feature/export-pdf

4. **`src/features/export-pdf/`** — экспорт в PDF и настройки:
   - `PdfExportFeature.vue` — кнопка "Download" + button "Settings"
   - `PdfMetadataPanel.vue` (уже есть в `src/components/pdf/`)
   - Логика: `usePdfExport`, управление `showPdfSettings`
   - Передача: `previewEl` и `meta` через props из page

5. **`src/features/switch-locale/`** — переключение языка:
   - `LocaleSwitchFeature.vue` — кнопки RU/EN переключение
   - Логика: `setLocale`, watch на изменение locale для локализации demo-resume
   - Side-effect: `pdfMetaStore.resetMeta()`, `resumeStore.localizeDemoResume()`

6. **`src/features/resume-uploader/`** (опционально, если выделить) или оставить в widgets
   - Можно интегрировать в ResumeFormWidget или выделить отдельно

7. **`src/features/performance-notice/`** — notice о performance:
   - `PerformanceNoticeWidget.vue` — вывод warning'ов
   - Логика: `evaluatePreviewPerformance`, вычисление `previewPerformanceNotice`
   - Получает `previewNaturalHeight`, `pageStarts` через props

8. **`src/features/reset-resume/`** — сброс резюме:
   - Простая функция/composable `useResetResume`
   - Кнопка в форме-хедере (в ResumeFormWidget или отдельно)

### Структурный результат
```
src/
  pages/builder/
    BuilderPage.vue  (только layout + activeTab state)
  widgets/
    resume-form/
      ResumeFormWidget.vue
    resume-preview/
      ResumePreviewWidget.vue
  features/
    export-pdf/
      PdfExportFeature.vue
    switch-locale/
      LocaleSwitchFeature.vue
    performance-notice/
      PerformanceNoticeWidget.vue
    reset-resume/
      useResetResume.ts
  components/  (как есть — базовые UI компоненты)
  entities/resume/  (как есть — доменная модель)
  stores/  (как есть)
  composables/  (как есть — низкоуровневые)
  utils/  (как есть)
```

### Инварианты, которые нужно сохранить

Согласно TECH-LEAD.md:
- **Пагинация:** `measurePagedLayout` — единственный источник истины. Любые изменения разметки превью должны сохранять `data-page-block` / `data-page-block-kind`.
- **i18n:** ключи через `t('…')` из `stores/locale`, язык документа синхронизируется через side-effect.
- **PDF-экспорт:** `pdfjs-dist` грузится лениво в `useResumeParser`, `optimizeDeps.exclude` в vite.config.ts.
- **Стили:** SCSS, `variables` и `mixins` глобально доступны.

## 4. План действий
