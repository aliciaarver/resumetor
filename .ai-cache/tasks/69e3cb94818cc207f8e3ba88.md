# Анализ задачи: Поддержать любые типы ссылок в контактах

**Дата анализа:** 2026-04-22

## 1. Что нужно сделать

В секции ссылок личной информации разрешить пользователю:
- Вводить произвольное название ссылки (кастомное имя), или
- Выбирать из расширенного списка популярных вариантов: Behance, Dribbble, Medium, X, Kaggle (кроме уже доступных Email, LinkedIn, Telegram, GitHub, Link)

**Текущее состояние:** только фиксированный набор из 5 типов (Email, LinkedIn, Telegram, GitHub, Link)

**Проблема:** специалисты вне backend/frontend (дизайнеры, писатели, аналитики) теряют семантику подписи в итоговом PDF, когда выбирают обобщенный «Link»

## 4. План действий

1. **Изменить хранилище данных:** добавить поле для названия типа ссылки (нестанд. значение или key из списка)
2. **Обновить UI:** заменить `<select>` с фиксированными опциями на комбинацию `<select>` (для популярных) + `<input>` (для кастома)
3. **Обновить валидацию:** убедиться, что произвольные строки валидны как идентификаторы/текст
4. **Обновить экспорт:** в PDF должно отображаться введенное пользователем название ссылки
5. **Обновить превью:** в интерактивной части должна видна кастомная подпись и ссылка должна быть кликабельна

## 5. Область
