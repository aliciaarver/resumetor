# Анализ задачи: Подсказывать, как писать сильное описание

## 1. Что нужно сделать

Добавить в конструктор интерактивные подсказки для полей "О себе" и "Описание роли":
- **Когда показывать:** при пустом поле или если пользователь явно их раскрыл
- **Что показывать:**
  - Короткий пример формулировки (образец текста)
  - Чек-лист "что упомянуть":
    - Формат достижений (метод, результат, цифры)
    - Ключевые слова из инструкций
    - Ожидаемая длина текста
- **Удобство:** подсказки можно свернуть и они не должны перекрывать ввод

## 2. Комментарии

Комментариев в карточке нет.

## 4. План работы

1. **Дизайн компонента:** определить, как выглядят подсказки (нужен макет или mock-up)
2. **Структура UI:**
   - Сворачиваемый блок рядом с полем ввода (или над ним)
   - Иконка "помощь" / кнопка "показать пример"
   - Пример текста в отдельной секции
   - Чек-лист с позициями
3. **Логика:**
   - Показывать подсказки по умолчанию только при пустом поле
   - Кнопка "свернуть/развернуть"
   - Локальное состояние (localStorage?) чтобы помнить выбор пользователя
4. **Контент:** выписать примеры и чек-листы для обоих полей

## 5. Критерии готовности (из задачи)

- ✓ В пустых описаниях виден пример формулировки и чек-лист
- ✓ Подсказки видны только когда поле пустое или пользователь их явно раскрыл
- ✓ Подсказки не перекрывают ввод
- ✓ Подсказки можно свернуть

## 6. Контекст продукта

**Resumetor** — одноразовый сеансовый инструмент (открыл → заполнил → скачал → закрыл). Функция не должна требовать:
- Сохранения настроек аккаунта
- Облачного хранилища
- Multi-resume логики

Подсказки — это вспомогательный интерфейс для улучшения качества резюме на лету.

## 7. Область задачи

Frontend — всё с экрана пользователя (UI компонент, показ/скрытие, интерактивность).

Специалист: frontend
