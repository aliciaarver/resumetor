# Задача: Ограничить размер и обрезать фото в профиле

## 1. Что нужно сделать

При загрузке фото автоматически:
- Сжимать его до разумного размера
- Предоставить простой инструмент кропа (квадрат или 3:4)
- Отклонять файлы крупнее заданного лимита с понятным сообщением

## 2. Комментарии

**Комментариев нет.**

## 3. Figma

Ссылка на макет не указана в описании задачи.

## 4. План действий

1. Определить лимит размера файла (нужен консенсус с дизайном/бэком)
2. Реализовать UI компонента загрузки с превью
3. Добавить кроп-интерфейс (квадрат / 3:4)
4. Сжимать фото перед отправкой на сервер
5. Обработать ошибки и показать уведомления
6. Тестировать экспорт PDF (не должен замедляться)

## 5. Зачем

Сейчас пользователь может загрузить многомегабайтный снимок с камеры → становится гигантским base64 → замедляет превью и экспорт → может некрасиво обрезаться.

## 6. Критерии готовности

- Загруженное фото обрезается до выбранной пропорции в интерфейсе
- Файлы сверх лимита вежливо отклоняются
- Экспорт PDF с фото остаётся быстрым и предсказуемым
