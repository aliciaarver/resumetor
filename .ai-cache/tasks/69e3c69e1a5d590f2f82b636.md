## 1. Что нужно сделать по задаче

Добавить статическую проверку кода и автоматизацию CI перед мерджем в основную ветку.

**Текущее состояние:**
- Push в main ничем не защищён
- TypeScript strict включен, но Vue и import правила lint не применяются
- Нет проверки кода перед коммитом

**Требуемое решение:**
1. Установить и настроить ESLint с плагинами:
   - `eslint-plugin-vue` — для Vue-специфичных ошибок
   - `@typescript-eslint` — для TypeScript проверок
   - `eslint-plugin-import` — для проверок импортов
   
2. Установить Prettier с поддержкой SCSS

3. Настроить GitHub Actions workflow:
   - install (зависимости)
   - lint (ESLint)
   - vue-tsc (TypeScript проверка)
   - build
   - test (когда появятся тесты)
   
4. Добавить pre-commit hook (простой-git-hooks или lefthook):
   - lint + typecheck для staged файлов

## 4. План работы

1. **Установить зависимости:**
   - eslint, prettier
   - eslint-plugin-vue, @typescript-eslint/parser, @typescript-eslint/eslint-plugin, eslint-plugin-import
   - simple-git-hooks или lefthook
   - @vue/vue3-essential (или equivalent ESLint config для Vue 3)

2. **Создать конфиги:**
   - `.eslintrc.js` (или `.eslintrc.json`) с указанными плагинами
   - `.prettierrc` или строка в `package.json`

3. **Настроить pre-commit hooks:**
   - Через `simple-git-hooks` или `lefthook` в `package.json` или `lefthook.yml`
   - Команда: `lint-staged` или `eslint --fix + vue-tsc --noEmit`

4. **Создать GitHub Actions workflow:**
   - `.github/workflows/ci.yml` с шагами: install → lint → vue-tsc → build → test

5. **Протестировать локально:**
   - Убедиться, что lint проходит
   - Убедиться, что pre-commit hook работает
   - Убедиться, что CI проходит
