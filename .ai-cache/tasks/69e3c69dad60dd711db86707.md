# Анализ задачи: Разнести i18n-словарь из stores/locale.ts

## 1. Что нужно сделать

**Рефакторинг архитектуры i18n:** вынести полный словарь, константы и доменные мэппинги из `src/stores/locale.ts`, чтобы тонкий store содержал только state-контейнер для текущей локали и методы доступа.

**Текущее состояние:**
- Файл `src/stores/locale.ts` — 550 строк
- Содержит:
  - Полный словарь переводов (Ru/En) — ~200 строк
  - Константу `PROFICIENCY_ORDER` с порядком уровней владения языком
  - Доменные мэппинги: `socialLinkLabel()`, `proficiencyLabel()`
  - Сайд-эффект: синхронизация `document.documentElement.lang`

**Требуемое состояние:**
- В store остаётся: `locale` (state), `t()` (translator), `setLocale()`, сайд-эффект на `<html lang>`
- Словари переводов → `src/shared/i18n/{ru,en}.ts` (или per-feature структура, как `features/upload-resume/i18n/ru.ts`)
- `PROFICIENCY_ORDER` → `entities/resume/lib/` (или ближе к типам)
- Доменные мэппинги `socialLinkLabel` / `proficiencyLabel` → `entities/resume/lib/`

**Соответствие архитектуре:**
- Нарушено: ADR-0001, раздел «Follow-up» — сторы должны быть state-контейнерами
- После рефакторинга: store станет тонким, доменная логика уедет в `entities/`

## 4. План работы

1. **Создать структуру `src/shared/i18n/`:**
   - `src/shared/i18n/ru.ts` — словарь русского языка (экспорт `messages.ru` из текущего файла)
   - `src/shared/i18n/en.ts` — словарь английского языка
   - `src/shared/i18n/index.ts` — переэкспорт обоих

2. **Извлечь доменные мэппинги в `src/entities/resume/lib/`:**
   - `src/entities/resume/lib/proficiencyLabel.ts` — функция `proficiencyLabel(value)` и константа `PROFICIENCY_ORDER`
   - `src/entities/resume/lib/socialLinkLabel.ts` — функция `socialLinkLabel(value)` (может остаться в composable, зависит от использования)
   - Обновить `src/entities/resume/lib/index.ts` (barrel) для переэкспорта

3. **Рефакторить `src/stores/locale.ts`:**
   - Удалить dictionary object `messages`
   - Импортировать уже извлечённые словари из `@/shared/i18n`
   - Оставить: `locale` state, `t()`, `setLocale()`, computed `proficiencyOptions` и `socialLinkOptions`
   - Сайд-эффект (`watch` на `document.documentElement.lang`) остаётся в store

4. **Обновить импорты в компонентах и composables:**
   - `useLocaleStore().proficiencyLabel()` → импорт из `@/entities/resume/lib`
   - `useLocaleStore().socialLinkLabel()` → импорт из `@/entities/resume/lib`
   - Проверить все места, где используются these функции

5. **Проверить типы и сайд-эффекты:**
   - Убедиться, что `PROFICIENCY_ORDER` доступен везде, где ранее брался из стора
   - Убедиться, что сайд-эффект на `<html lang>` работает с новой структурой

6. **Тестирование:**
   - Запустить dev-сервер (`npm run dev`)
   - Проверить переключение языка RU/EN
   - Проверить, что `<html lang>` синхронизируется
   - Проверить, что dropdown'ы с уровнями владения языком и ссылками работают
