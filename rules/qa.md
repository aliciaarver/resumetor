# QA Rules

## Перед сдачей любой задачи проверить

### Frontend
- [ ] Компонент рендерится без ошибок в консоли
- [ ] `vue-tsc --noEmit` — ноль ошибок TypeScript
- [ ] Состояние загрузки отображается корректно
- [ ] Ошибки API показываются пользователю понятным текстом
- [ ] Верстка не ломается при длинном тексте в данных
- [ ] Верстка не ломается при пустых данных

### Backend
- [ ] Все обязательные поля запроса валидируются
- [ ] Ошибки внешних API возвращаются с понятным сообщением
- [ ] Нет упавших промисов без catch
- [ ] Токены не попадают в логи

## Воспроизведение бага
При работе с багом обязательно:
1. Описать шаги воспроизведения
2. Указать ожидаемое и фактическое поведение
3. Проверить что баг воспроизводится до фикса
4. Проверить что баг не воспроизводится после фикса

## Регрессия
После изменений проверить что не сломалось:
- Вход / выход (LoginScreen)
- Загрузка задач (KanbanBoard)
- Открытие деталей задачи
- Кнопки "Прочитать задачу" и "Писать код"

## Что не считается готовым
- Работает только на одном наборе данных
- Нет обработки пустого ответа от API
- TypeScript ошибки замолчаны через `// @ts-ignore`
- Проверено только в одном браузере
