# Коммиты — компактные правила

## Ветка

- **Задача из трекера** (запуск через «Работать над задачей»): работаешь на ветке = ID задачи (`PROJ-142`, `abc123xy`), туда же идут коммит и пуш.
- **Правки без задачи** — рефакторинг, улучшения самого дашборда, мелкие фиксы по прямой просьбе разработчика: коммит и пуш **прямо на `main`** (или как называется основная ветка — проверь через `git symbolic-ref refs/remotes/origin/HEAD`). Никаких временных feature-веток.
- `git push --force` на `main`/`master` — никогда.

## Формат

```
<тип>(<ID задачи>): <краткое описание>
```

### Тип (один из)
- `feat` — новая функциональность (кнопка, роут, эндпоинт, поле в ответе).
- `fix` — исправление бага (виден пользователю или ломает сборку/тесты).
- `refactor` — изменение кода без смены поведения.
- `style` — форматирование, whitespace, CSS без логики.
- `docs` — правки документации (CLAUDE.md, README.md, TECH-LEAD.md, PM.md, rules/).
- `test` — добавление или правка тестов.
- `chore` — конфиги, зависимости, скрипты сборки, .env, .gitignore.
- `perf` — оптимизация производительности.

### ID задачи
- YouTrack — readable ID (`PROJ-142`).
- Trello — shortLink из URL карточки (кусок после `/c/`, до следующего `/`).

### Описание
- До 72 символов на весь subject.
- Русский (язык проекта). Технические термины на английском оставляй: `debounce`, `CORS`, `polling`.
- Без точки в конце.
- Описывай смысл изменения, а не имена файлов.

## Дисциплина

- **Один коммит — одна цель.** Если появляется «и ещё я заодно…» — это второй коммит.
  - Баг-фикс + рефакторинг → два коммита.
  - Фикс бэка + не связанный фикс фронта → два коммита.
  - Правки кода + обновление зависимостей → два коммита (`chore` отдельно).
- Сообщения `wip`, `fix`, `update`, `stuff`, `misc`, `temp`, `.` — запрещены.
- **Не упоминай инструмент:** никаких `Claude: ...`, `via Claude Code`, `Co-Authored-By: Claude` в теле.
- **Эмодзи** — только если в `git log` проекта они уже есть.

## Примеры

Хорошо:
```
feat(PROJ-142): автообновление доски пока Claude работает над задачей
fix(abc123xy): распознал колонку «На тестировании» в разных написаниях
chore(PROJ-157): добавил шаг переноса карточки в completionNote
refactor(PROJ-203): вынес readDisabled/writeDisabled в computed
```

Плохо:
```
update files                          # нет типа, нет ID задачи
feat(BoardView.vue): добавил поллинг  # в скоупе ID задачи, не имя файла
Claude: add polling                   # имя модели + не на русском
feat: исправил баг                    # тип `feat` для фикса + нет ID
wip                                   # запрещено
```
