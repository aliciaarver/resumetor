# QA — компактные правила

## Перед сдачей задачи
Frontend:
- Нет ошибок в консоли.
- `vue-tsc --noEmit` — ноль ошибок.
- Loading-состояния отображаются.
- Ошибки API показаны пользователю.
- Вёрстка переживает длинные тексты и пустые данные.

Backend:
- Обязательные поля валидируются.
- Ошибки внешних API возвращаются с понятным сообщением.
- Нет неперехваченных промисов.
- Токены не в логах.

## Баги
- Описал шаги воспроизведения, ожидаемое vs фактическое.
- Баг воспроизводится до фикса.
- Баг не воспроизводится после фикса.

## Регрессия
После изменений проверь: логин, загрузку задач, детали задачи, кнопки «ИИ анализ» / «Работать над задачей».

## Не готово
- Работает только на одном наборе данных.
- Нет обработки пустого ответа API.
- Заглушен через `@ts-ignore`.
- Проверено в одном браузере.
